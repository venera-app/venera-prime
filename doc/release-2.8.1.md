# Venera Prime 2.8.1

## 本次更新

- **网络请求取消时闪退 #55**（@fanhua2006）：修复请求超时或取消后，延迟返回的网络回调触发原生库 abort 的问题；同时处理无效请求方法、缺失上传流、自定义 DNS 异常等相似错误路径。已复现并消除与反馈相同的原生崩溃堆栈，仍请在原设备、不挂 VPN 的启动场景复查。
- **非默认目录刷新与恢复 #53**（@lzx377z）：补齐 Android 授权目录的属性查询和文本读写。“设置 → 应用 → 刷新本地库”与“导入 → 恢复本地下载”可读取漫画元数据，不再因缺少 stat/readAsString 实现抛出 UnimplementedError；未知修改时间不会覆盖已有漫画的创建时间。
- **通用 SAF 存储目录 #54**（@GalahadVi）：保留 DocumentsProvider 的完整目录标识，按真实文档 ID 读写、创建和扫描，不再假定所有授权目录都是系统本地存储。兼容旧目录配置；服务暂时离线时保留用户所选目录，写入失败如实报告，兼容仅支持 wt 的 Provider。下载、阅读、导出与目录迁移共用修正后的文件访问链路。
- **阅读图片刷新与长按 #49**（@sakana155）：刷新时清除实际图片缓存，防止此前的下载晚返回后覆盖刷新结果；长按缩放等待控制器就绪，退出阅读器后取消延迟手势。**JM 偶发纯黑图本身仍未稳定复现，不能据此认定所有黑图已解决。**
- **更多主题色与自选颜色**：在“设置 → 外观 → 主题颜色”选择系统色、18 种预设色或自定义色；支持 RGB 滑块和六位 HEX 输入、错误提示与取消编辑，重启后保留选择。
- **外部链接冷启动与页码跳转**：等待漫画源、首页导航和启动解锁完成后再处理外部链接，避免应用未启动时丢失跳转。识别 nhentai 与 e-hentai/exhentai 已知链接结构中的末尾页码，详情加载成功后进入指定页；未知链接不盲目删除末尾数字。阅读器打开时收到普通漫画链接，详情现在显示在阅读器上方。

## 请更新后验证并反馈

请关联 issue 的提出者安装 **2.8.1**，按原来的复现步骤复查。已解决时，请在原 issue 确认，并及时关闭尚未关闭的 issue；仍存在时，请提供版本号、系统与设备、漫画源、复现步骤及必要的日志或录屏。已关闭的问题也可继续留言或重新打开。

日志、截图和录屏请遮盖账号、密码、令牌及 WebDAV 私有地址等敏感信息。闪退请尽可能附系统 crash/logcat，应用内日志可能记录不到原生崩溃。关联 issue 不代表所有设备、漫画源与服务端均已验证，本次发布不会自动关闭 issue。
