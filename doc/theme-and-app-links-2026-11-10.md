# 主题色与 Android 外部链接（2026-11-10）

## 主题色

沿用“设置 → 外观 → 主题颜色”，提供 18 种预设色、系统色及自定义色。新增自定义颜色对话框，支持 RGB 滑块、六位 HEX 输入、无效值提示和取消操作。应用后即时更新；自定义 RGB 与当前选择随 appdata 设置持久化。切换到其他颜色时仍保留上次自定义色。

移除颜色切换时多余的 App.init()，仅重建主题。简体、繁体文案已补充。

## 冷启动外部链接

原逻辑在收到链接后立即遍历漫画源，但漫画源启动延迟至少 500ms；导航未建立时只等待一次 200ms，因此可能解析不到源或没有导航上下文，却不保留链接。

新逻辑订阅一次 app_links 流（该插件会通过流发送 initial intent），将链接排队，等待漫画源初始化成功、首页 Navigator 挂载、启动声明/解锁流程完成。锁屏或导航销毁时暂停队列。关闭 Flutter 自带 deep-link 路由处理，避免与 app_links 重复处理同一 VIEW intent。异常源解析不会阻止后续来源和后续链接。

对已注册站点的 gallery 页码 URL 做明确结构匹配：

- `nhentai.net/g/<id>/<page>`，可带末尾斜杠。
- `e-hentai.org` / `exhentai.org` 的 `g/<id>/<token>/<page>`。

解析时向漫画源传入 gallery 地址，并把正整数页码传给漫画详情页；详情加载成功且页面仍处于前台时打开该页阅读。不对未知站点盲目删除末尾数字，也不会把 gallery ID/token 误当成页码。

- 自动测试覆盖冷启动等待、重复就绪通知、锁定期间保留链接、单个链接异常不堵塞队列、带/不带斜杠的页码 URL，以及不应裁剪的普通链接。
- 主题测试覆盖 HEX 合法性、RGB 滑块同步、自定义值回退和实际落盘后读取。
- `integration_test/app_link_probe.dart` 使用独立测试包，测试前以 aapt 核对 package。真实 ADB VIEW intent 验证：冷启动时源故意延迟 3 秒，`g/123/7/` 到达 ComicPage 时为 id=123、page=7；运行中 `g/456/9` 为 id=456、page=9。之后再次冷启动验证挂载门控。

## 实际界面 ADB 复测

使用 `integration_test/manual_app.dart` 启动完整应用，在 HUAWEI TAS-AN00 / Android 12 上手动操作。构建后通过 aapt 核实独立包名，再用 adb 覆盖安装测试包；未使用 Flutter 设备测试驱动，正式包安装路径前后保持不变。测试包关闭 WebDAV 同步，避免测试数据上传。

- 真实源冷启动链接进入阅读器第 2/14 页，运行中带页码链接进入第 5/14 页。
- 发现并修复：阅读器占据根 Navigator 时，普通漫画链接此前压入首页的嵌套 Navigator，详情页被阅读器遮挡。现在有根导航覆盖页面时使用根 Navigator；真机复测详情页正常显示在阅读器上方，新增 `app_link_navigation_test.dart` 回归测试。
- 实际设置界面验证预设色、HEX 错误提示与禁用应用、有效 HEX、RGB 滑块及取消操作。设置 `#0F766E` 和深色模式后强制停止再启动，选择仍保留。
- 导航、链接队列和主题相关测试共 7 项通过；analyzer 仅有既存 `about.dart:59` 提示。
- 本轮未观察到应用崩溃；日志仍有现有 `comic_walker` 源脚本的 `ReferenceError: response is not defined`，不属于已验证通过的项目。
