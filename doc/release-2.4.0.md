# Venera Prime 2.4.0

## 新功能

- 阅读器屏幕方向行为改为四选一下拉设置：退出后保持旋转、退出后恢复旋转前状态、所有漫画共用记忆、按漫画分别记忆。
- 屏幕方向模式可在全局设置和阅读器内直接切换；阅读器内修改会立即作用于当前阅读会话。
- 首页新增“百宝箱”入口，集中提供搜图bot酱与 SauceNAO 两个图片搜索工具，并使用内置浏览器打开。

## 改进

- 旧版两个屏幕方向开关会自动迁移到对应的新模式，已有使用习惯与按漫画保存的方向记录不会丢失。
- 搜图网页跳转到已支持的漫画详情链接时，会尝试交回 Venera Prime 打开。
- 屏幕方向行为与按漫画方向记录继续仅保存在本机，不参与跨设备同步。

## 验证

- Flutter 静态检查通过。
- 86 项自动化测试通过，另有 2 项按设计跳过。
- Android Profile 构建已在华为 TAS-AN00 真机验证：四种屏幕方向模式、阅读器内切换、百宝箱布局以及两个内置搜图网页均可正常使用。
- 其他平台正式产物以 GitHub Actions 结果为准。
