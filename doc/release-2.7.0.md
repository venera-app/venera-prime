# Venera Prime 2.7.0

## 本次更新

- **搜索历史与页码恢复**：历史条目显示搜索词、漫画源胶囊、源定义的筛选属性和上次浏览页码；同词不同源或不同筛选分别记录。点击条目恢复来源、筛选及对应页顶部。聚合搜索单独记录，从聚合进入单源列表也会建立记录。连续模式记录实际可见结果所属页，预加载不会提前推进历史，回滚也会更新页码；页与页之间增加细虚线和小号页码。只能使用游标翻页的源逐页恢复并显示进度，可取消；来源失效时提示重新选择，选项变化时回退到当前默认值及第一页。保留旧历史及复制、删除、清空功能，翻页合并本地保存，离开搜索时再同步。
- **本地下载管理 #38**（@suppermanzero）：本地列表显示漫画体积和来源，操作菜单可进入详情、继续阅读或直接选择已下载章节；新增漫画及分类排序、新建／重命名／删除分类、批量移动。分类为应用内虚拟分类，不移动实际文件；删除分类不会删除漫画。离线进度指向未下载章节时回退到已下载章节。
- **双页排版与跨页 #47**（@zklall）：双页保持各自比例并统一页高，宽图可独占展开页；支持手动固定配对、逐图调整和恢复自动排版，按漫画及章节保存。双击可聚焦单页，再次双击还原；保留阅读方向、封面单页、尾页空位及切换后的原图位置。参考并整合提出者提供的实现。
- **首页单张时的图片移位 #34**（@MisakaTukasa）：开启首页单张后，“后移一张图片”可将下一张并入首页；从第二组前移到首页时也会调整首组配对。
- **连续阅读按屏幕翻页 #46**（@GalahadVi）：连续阅读的点击、按键等翻页操作每次移动约 90% 视口，保留少量重叠，长图不会整张跳过；只有到达章节实际滚动边界后才进入相邻章节。
- **章节混合名称排序 #48**（@zklall）：统一按卷号、话号比较纯数字及中英文前缀章名，支持中文数字、全角数字和小数话数；同话号保持原顺序，章节 ID 与阅读记录映射不变。本地导入及扫描同时接入，“源默认排序”仍保留源顺序。整合提出者提供的修复。
- **大 ZIP／CBZ 导入 #45**（@Arteiimis）：归档预检和解压改用文件后备流，压缩文件上限从 512 MiB 调整为 2 GiB，避免将整包读入内存；继续保留总展开量 1 GiB、单条 256 MiB、条目数量、压缩比和路径等安全限制。
- **EPUB 导出与 Android 文件读写 #43**（@lzx377z）：修正 EPUB 图片引用、XML 转义和并发导出临时目录冲突；Android 系统文档目录读写处理短读、短写和长度未知的文件，并收紧并发句柄及 JNI 引用生命周期。请在原荣耀设备及原漫画上复查导出缺图与本地空图片。
- **阅读页重新加载与图片处理 #49**（@sakana155）：顶部新增重新加载入口，清理当前可见页缓存后重载并保留位置；修正异步图片处理失败后等待不结束、旧取消流干扰新加载、像素通道及编码偏移等问题。原始禁漫黑图未复现，不能据此保证其根因已解决。
- **图片收藏横向滚动 #50**（@lzx377z）：每条图片收藏列表使用独立滚动控制器，支持桌面鼠标拖动及可拖动滚动条；仍需在原 Windows 环境复查。
- **更新检查期间的 WebDAV 上传**：检查收藏更新时，漫画源保存数据产生的自动上传请求合并，在最后一批检查结束后触发一次；异常和取消也会释放批处理。手动上传仍可执行，关闭自动同步会阻止最终自动上传。
- **Windows 代理与存储路径切换**：修正系统代理读取失败、协议代理列表解析及原生内存释放；迁移存储目录改为分块复制，完整复制并持久化后再切换路径，旧目录因文件占用清理失败时保留旧文件并记录错误。仍须选择空目录、完成或取消排队下载；Windows WebDAV 原环境尚未验证。
- **下载暂停／继续及完成入库**：同一任务的异步运行串行化，旧任务回调不再调度新章节；完成入库和队列保存可等待，入库失败保留可重试任务。结合 Android 文件读写修正降低竞争与资源泄漏风险；尚未取得原始拷贝漫画闪退任务，仍需原环境复查。
- **项目说明与交流入口**：增加仅在本机首次确认前展示的项目说明，老用户升级后也会看到；说明非官方分支、LLM 辅助维护、个人本地／NAS 漫画阅读用途及通过 Fork + Issue 请求合并的贡献方式。“设置 → 关于”可重看说明，提供独立 Telegram 群及标明归属的上游群入口。README 同步更新英文说明。
- **历史界面**：移除常驻的“尚未检查”等更新状态文字，相关任务信息仍在后台任务中查看。
