# Venera Prime 2.3.2

## 新功能

- 新增“仅在阅读器中记忆屏幕方向”：进入阅读器时恢复上次方向，退出后恢复进入前的方向，不影响应用其他页面。
- 新增“按漫画分别记忆屏幕方向”：可按漫画源与漫画 ID 独立保存阅读方向。
- 新增收藏夹名称点击行为设置，可选择打开收藏夹侧边栏或返回收藏概览。

## 改进

- 阅读方向偏好与记录仅保存在本机，不参与跨设备同步。
- 默认保持原有行为：阅读器旋转会继续影响退出后的界面，点击收藏夹名称会打开侧边栏。

## 验证

- Flutter 静态检查通过。
- 81 项自动化测试通过，另有 2 项按设计跳过。
- Android Profile 构建已在华为 TAS-AN00 真机验证，包括阅读方向全局记忆、按漫画隔离、退出恢复，以及本地和网络收藏夹的两种标题点击行为。
