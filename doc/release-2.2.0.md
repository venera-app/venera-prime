# Venera Prime 2.2.0

## 新增与改进

- 多源目录管理：支持添加、编辑、启停、排序与删除目录，记录漫画源归属并支持切换提供方。
- 手动绑定：在检查更新旁为未绑定漫画源提供归属分配入口，可选择目录中的相同 key 条目，不替换当前脚本。
- 首页自定义：支持模块显隐、拖动排序和恢复默认。入口位于首页设置按钮左侧，也可从设置的外观页面进入。
- 首页布局和源目录配置纳入现有备份及 WebDAV 同步。

## 修复

- 修复 WebView 登录错误调用 Android 专属 API 导致的跨平台 UnimplementedError。
- 修复原版旧 ZIP 备份的条目大小读取兼容问题，并改进恢复失败时的文件及内存状态回滚。
- 恢复源账号、密码、token 和 Cookie 的备份、导入与 WebDAV 同步；手动导入支持恢复 WebDAV 配置，自动同步保留当前设备连接配置。
- 改进下载失败后的手动重试及下载状态处理。
- 修复关于页翻译与文本对齐，以及失效动态源选项导致设置入口消失的问题。
- 改进源更新候选失效处理及发布产物收集，包含 Linux AppImage。

## 注意事项

- 备份包含未加密的凭据，请妥善保管，不要公开分享；建议使用可信的 HTTPS WebDAV 服务。
- 之前已过滤掉凭据的备份无法补回缺失数据，过期或被服务器撤销的登录状态仍需重新登录。
- 多源指脚本目录与提供方管理，不是跨站漫画合并或同 key 多版本并行运行。请仅使用可信目录。
- 多源首次安装的目录 key 核对、切换中断时的完整一致性及部分异常流程仍待完善。
- Windows/iOS 原生登录尚未完成本轮实机验证；JM 特定网络环境下的 TLS 握手失败未确认解决。

## 验证

- 本地静态检查及 69 项自动化测试通过（另有一项默认跳过的在线诊断）。
- Android/Linux 调试构建通过，已进行 Android 真机首页交互及部分源目录功能检查。
- 各平台正式安装包由 GitHub Actions 构建并上传，请以本次工作流结果和附件为准。
