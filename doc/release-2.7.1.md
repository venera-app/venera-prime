# Venera Prime 2.7.1

## 本次更新

- **瀑布流跨章节阅读**：在阅读设置中选择“连续（从上到下）”，再开启“瀑布流阅读（跨章节）”，即可沿同一滚动列表继续阅读同组的前后章节；章节之间显示分隔线和章节名。向上加载时保留可见位置，阅读记录随实际可见章节和页码更新；遵循章节阅读方向，加载失败可在边界重试。横向连续及画廊模式仍沿用原有行为。
- **收藏夹首页模块**：从现有“自定义首页”入口进入，点击右上角加号选择本地收藏夹，以横向封面列表展示；可排序、隐藏或删除模块，点击标题进入对应收藏夹。删除模块不会删除收藏内容；收藏夹被删除或重命名时会提示重新添加。
- **紧凑首页**：在“自定义首页”右上角设置中开启“紧凑首页”，压缩控件高度和模块留白；历史、待读、本地及收藏夹预览的封面宽高同比缩小，并计入内边距，避免仅压缩高度造成额外裁切。继续使用原有自定义入口，不增加重复按钮。
- **漫画源页面白屏**：修复源设置的下拉选项文字过长时占满整行、触发布局异常并使整页无法显示的问题。选择框移到标题下方，闭合状态的长文字按可用宽度省略，展开菜单仍能查看完整选项。

- 新增回归覆盖瀑布流向上插入章节、双向跨章、倒序阅读和阅读记录，以及首页模块配置保存、紧凑开关、窄屏漫画源长选项布局及菜单展开。章节与漫画源布局用例包含本地生成图片和模拟漫画源，不代表所有第三方源均已验证。

- 正式发布采用 Android、iOS、macOS、Windows、Linux x64、Linux ARM64 六平台及十四个标准附件的机器人流程，以六平台及 Release 任务全部成功作为发布完成条件。iOS 为未签名 IPA；构建成功不等于平台真机验证。不额外下载或核验线上附件及签名。
