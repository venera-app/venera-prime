# Venera Prime 2.3.0

## 新增与改进

- 重做收藏夹入口：默认展示收藏夹总览，本地收藏位于网络收藏上方；侧边栏新增返回总览的入口。
- 收藏夹总览采用更紧凑的字号、图标和间距，并支持在一至四栏之间切换，布局偏好会自动保存。
- 阅读统计新增隐私控制：可暂停或恢复统计、清空全部统计，也可单独删除某部漫画的统计记录。

## 修复

- 修复本地下载漫画删除后，使用“恢复本地下载”仍会再次出现的问题。
- 修复 EH 同步书签时一次只能新增一本的问题，批量同步现在会完整处理本次新增内容。
- 修复禁漫天堂启动时域名列表刷新可能未生效、重启后未正确使用新域名的问题，并增强网络组件初始化时序的健壮性。
- 降低下载和阅读时的界面卡顿：合并重复图片请求、减少不必要的缓存与状态落盘，并对高频进度更新进行节流。
- 改进图片加载、下载队列恢复和本地文件路径处理，减少重复工作与异常状态残留。

## 隐私说明

- 暂停阅读统计后，新的阅读行为不会写入统计；已有数据会保留，直至用户单独删除或清空。
- 阅读统计仅保存在本地，相关删除操作不可撤销。
