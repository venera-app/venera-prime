## #53：SAF 刷新 / 恢复报 UnimplementedError

补齐 AndroidFile 的文本读写、逐行读取和 File/Directory.stat；属性来自 DocumentsProvider 查询，文件大小使用 64 位值。刷新和恢复使用的修改时间为未知值时，新漫画使用当前时间；已有记录的创建时间仍保留。

真机验证覆盖 metadata.json、中文文本、文件大小、目录类型及本地库 refresh。后续通过独立测试包的完整应用界面执行“设置 → 应用 → 刷新本地库”，正常提示 0 部新增、0 部缺失；“导入 → 恢复本地下载”正确跳过已有漫画。向测试 Provider 加入另一份无害漫画夹具后，再次恢复显示“已导入 1 本漫画”，本地数量由 1 变为 2，未出现 UnimplementedError。此验证使用测试 Provider，并非真实 WebDAV 服务。

## #54：通用 DocumentsProvider 目录

- 新选择的虚拟根路径编码完整 tree URI，保留 authority，避免不同 Provider 的相同 tree ID 冲突；兼容已有 ExternalStorage Provider 的旧路径。
- 通过逐层查询显示名称获得真实 document ID，递归创建目录不再拼接文档 ID。根匹配采用边界前缀，拒绝路径穿越。
- 目录查询失败抛出文件系统异常，不返回伪空目录；文件名中的 `|` 与 Unicode 可正确往返。
- 句柄采用无哈希碰撞的 ID，按 URI 维护引用计数；Dart 替换句柄时同步更新 finalizer，复制文件不改变原对象。
- SAF 的父目录与类型判断使用 SAF 路径；本地库删除使用独立的 SAF 子路径检查，普通目录原有符号链接检查保留。
- 云端暂时离线或权限失效时不覆盖保存的本地目录配置；`.nomedia` 失败不使启动失败。
- 写入失败向上传递。对不支持 `rwt` 的 Provider，在其明确拒绝该模式时尝试 `wt`。

已查看 alexbakker/webdav-provider 的 `WebDavProvider.openDocument`：其仅接受 `r`、`w`、`wt`。本轮测试夹具也只接受这些模式。未连接真实 WebDAV 服务器，不能把夹具验证等同于该第三方应用所有功能均已实测。

## #49：长按异常、图片刷新失效

- 相册与连续阅读在控制器 / 初始缩放尚未就绪时忽略缩放；松手只处理本次长按对应的控制器和章节。
- 长按延迟回调检查页面、章节和 mounted；退出阅读器时取消手势定时器并释放 TapGestureRecognizer。
- 刷新会解开 ResizeImage，清除实际磁盘缓存及相关 Flutter 图片缓存。
- 使旧的共享下载失效，避免刷新前的请求晚返回后重新写入旧缓存。
- 图片解码失败时使用实际磁盘缓存 key，避免删错缓存而反复加载坏数据。

已验证上述确定问题。JM 偶发纯黑图本身仍未稳定复现；不能据此断言所有黑图已根治。
